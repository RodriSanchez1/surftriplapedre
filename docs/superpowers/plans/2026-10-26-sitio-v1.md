# Sitio v1 del surftrip: plan de implementación

> **Para agentes:** SUB-SKILL OBLIGATORIA: usar superpowers:subagent-driven-development (recomendado) o superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan checkboxes (`- [ ]`) para el seguimiento.

**Objetivo:** reemplazar el `index.html` actual por un sitio Astro estático en GitHub Pages, con home, calendario del trip, página por sesión y por surfista, en ES y PT y con el design system "Board Graphic". Además, documentar el workflow con IA en `AGENTS.md`.

**Arquitectura:** el contenido vive en YAML (`src/data/`) y markdown (`src/content/`), validado con colecciones de Astro y zod. La lógica con reglas (i18n, calendario, fallback de idioma, chequeos de integridad) está en módulos TypeScript puros en `src/lib/`, con tests de Vitest. Las vistas (`src/views/`) reciben `lang` y las páginas de `src/pages/` y `src/pages/pt/` son envoltorios de una línea. Nada específico del trip está en el código: todo sale de los datos.

**Stack:** Node 24, Astro 7, TypeScript 6, Vitest 5, zod 4 (vía `astro/zod`), @fontsource (Bungee, Bungee Shade, Archivo Black), DiceBear 9 para avatares, Playwright para capturas y GitHub Actions (`withastro/action@v6` + `actions/deploy-pages@v5`).

**Spec:** `docs/superpowers/specs/2026-10-26-sitio-v1-design.md`

**Modelo por tarea:** cada tarea indica qué modelo usar para el subagente (Haiku, Sonnet u Opus), según el workflow de `AGENTS.md`.

```ts
/** Domingo = 0, como Date.getUTCDay(). */
export const WEEKDAYS: Record<Lang, readonly string[]> = {
  es: ['Dom', 'Lun', 'Mar', 'Mié', 'Jue', 'Vie', 'Sáb'],
  pt: ['Dom', 'Seg', 'Ter', 'Qua', 'Qui', 'Sex', 'Sáb'],

export function t(lang: Lang, key: UiKey): string {
  return ui[lang][key];
}

export function isLang(value: string): value is Lang {
  return (LANGS as readonly string[]).includes(value);
}

function trimSlashes(s: string): string {
  return s.replace(/^\/+|\/+$/g, '');
}

/** Arma una URL interna: base + prefijo de idioma + ruta, siempre con barra final. */
export function pathFor(lang: Lang, path: string, base: string): string {
  const parts = [trimSlashes(base), lang === DEFAULT_LANG ? '' : lang, trimSlashes(path)].filter(Boolean);
  return parts.length ? `/${parts.join('/')}/` : '/';
}

/** Separa una URL interna en idioma y ruta sin base ni prefijo. */
export function parsePath(pathname: string, base: string): { lang: Lang; path: string } {
  let rest = trimSlashes(pathname);
  const b = trimSlashes(base);
  if (b && (rest === b || rest.startsWith(`${b}/`))) rest = trimSlashes(rest.slice(b.length));
  const [first, ...others] = rest.split('/');
  if (first && first !== DEFAULT_LANG && isLang(first)) return { lang: first, path: others.join('/') };
  return { lang: DEFAULT_LANG, path: rest };
}

/** La misma página en otro idioma. */
export function switchLang(pathname: string, base: string, target: Lang): string {
  return pathFor(target, parsePath(pathname, base).path, base);
}
```

```ts
/** Fechas en formato ISO 'AAAA-MM-DD'. Se calculan en UTC para no depender de la zona del build. */
export type IsoDate = string;
export type DayState = 'past' | 'today' | 'future';

export interface CalendarDay<T> {
  fecha: IsoDate;
  /** 0 = domingo, como Date.getUTCDay(). */
  weekday: number;
  dia?: T;
}

const DAY_MS = 86_400_000;

function toUtc(fecha: IsoDate): number {
  return Date.parse(`${fecha}T00:00:00Z`);
}

/** Todas las fechas entre inicio y fin, ambas incluidas. */
export function tripDates(inicio: IsoDate, fin: IsoDate): IsoDate[] {
  const start = toUtc(inicio);
  const end = toUtc(fin);
  if (Number.isNaN(start) || Number.isNaN(end) || end < start) {
    throw new Error(`Rango de fechas inválido: ${inicio} → ${fin}`);
  }
  const out: IsoDate[] = [];
  for (let ms = start; ms <= end; ms += DAY_MS) out.push(new Date(ms).toISOString().slice(0, 10));
  return out;
}

export function weekdayOf(fecha: IsoDate): number {
  return new Date(toUtc(fecha)).getUTCDay();
}

/** '2026-10-26' → '26/10' */
export function dayMonth(fecha: IsoDate): string {
  const [, m, d] = fecha.split('-');
  return `${d}/${m}`;
}

/** Une el rango del trip con los días cargados en dias.yaml. */
export function buildCalendar<T extends { id: IsoDate }>(inicio: IsoDate, fin: IsoDate, dias: T[]): CalendarDay<T>[] {
  const byDate = new Map(dias.map((d) => [d.id, d]));
  return tripDates(inicio, fin).map((fecha) => ({ fecha, weekday: weekdayOf(fecha), dia: byDate.get(fecha) }));
}

/** La fecha de hoy en una zona horaria, como 'AAAA-MM-DD'. */
export function todayIn(timeZone: string, now: Date = new Date()): IsoDate {
  return new Intl.DateTimeFormat('en-CA', { timeZone, year: 'numeric', month: '2-digit', day: '2-digit' }).format(now);
}

export function dayState(fecha: IsoDate, today: IsoDate): DayState {
  if (fecha === today) return 'today';
  return fecha < today ? 'past' : 'future';
}
```

```ts
import { DEFAULT_LANG, isLang, type Lang } from './i18n';

/** Los archivos de contenido se llaman '<base>.<lang>.md'; su id es '<base>.<lang>'. */
export function splitLangId(id: string): { base: string; lang: Lang } {
  const dot = id.lastIndexOf('.');
  const lang = dot === -1 ? '' : id.slice(dot + 1);
  if (!isLang(lang)) throw new Error(`El id "${id}" no termina en un idioma conocido (.es o .pt)`);
  return { base: id.slice(0, dot), lang };
}

export interface Localized<T> {
  entry: T;
  /** true si se pidió otro idioma y se devolvió el español. */
  fallback: boolean;
}

/** Busca la versión de un contenido en un idioma; si no existe, usa la de español. */
export function pickLang<T extends { id: string }>(entries: T[], base: string, lang: Lang): Localized<T> | undefined {
  const exact = entries.find((e) => e.id === `${base}.${lang}`);
  if (exact) return { entry: exact, fallback: false };
  const def = entries.find((e) => e.id === `${base}.${DEFAULT_LANG}`);
  return def ? { entry: def, fallback: lang !== DEFAULT_LANG } : undefined;
}

/** Un elemento por contenido (sin repetir idiomas), en el idioma pedido o con fallback. */
export function localizeAll<T extends { id: string }>(entries: T[], lang: Lang): Localized<T>[] {
  const bases = [...new Set(entries.map((e) => splitLangId(e.id).base))];
  return bases.map((b) => pickLang(entries, b, lang)).filter((x): x is Localized<T> => x !== undefined);
}

interface InsightLike {
  id: string;
  data: { surfista: string; fecha: string };
}

/** Insights de un surfista en un idioma, del más reciente al más viejo. */
export function insightsForSurfer<T extends InsightLike>(entries: T[], surfistaId: string, lang: Lang): Localized<T>[] {
  return localizeAll(
    entries.filter((e) => e.data.surfista === surfistaId),
    lang,
  ).sort((a, b) => b.entry.data.fecha.localeCompare(a.entry.data.fecha));
}

/** Insights de una sesión en un idioma, en el orden de la lista de surfistas. */
export function insightsForSession<T extends InsightLike>(
  entries: T[],
  fecha: string,
  lang: Lang,
  surfistaOrder: string[],
): Localized<T>[] {
  const rank = (id: string) => surfistaOrder.indexOf(id);
  return localizeAll(
    entries.filter((e) => e.data.fecha === fecha),
    lang,
  ).sort((a, b) => rank(a.entry.data.surfista) - rank(b.entry.data.surfista));
}
```

```ts
import { splitLangId } from './localized';

export interface IntegrityInput {
  trip: { fechaInicio: string; fechaFin: string };
  surfistaIds: string[];
  dias: { id: string; sesion?: string }[];
  sesionIds: string[];
  insights: { id: string; data: { surfista: string; fecha: string } }[];
}

/** Revisa las referencias entre archivos de contenido. Devuelve un error legible por problema. */
export function findContentErrors({ trip, surfistaIds, dias, sesionIds, insights }: IntegrityInput): string[] {
  const errors: string[] = [];
  const surfistas = new Set(surfistaIds);
  const sesiones = new Set(sesionIds.map((id) => splitLangId(id).base));

  for (const dia of dias) {
    if (dia.id < trip.fechaInicio || dia.id > trip.fechaFin) {
      errors.push(`dias.yaml: el día ${dia.id} está fuera del trip (${trip.fechaInicio} → ${trip.fechaFin})`);
    }
    if (dia.sesion && !sesiones.has(dia.sesion)) {
      errors.push(`dias.yaml: el día ${dia.id} apunta a la sesión ${dia.sesion}, que no tiene src/content/sesiones/${dia.sesion}.es.md`);
    }
  }

  for (const insight of insights) {
    const { base } = splitLangId(insight.id);
    const [carpeta, archivo] = base.split('/');
    if (!surfistas.has(insight.data.surfista)) {
      errors.push(`insights/${insight.id}.md: el surfista "${insight.data.surfista}" no está en surfistas.yaml`);
    }
    if (carpeta !== insight.data.fecha) {
      errors.push(`insights/${insight.id}.md: la fecha ${insight.data.fecha} no coincide con la carpeta ${carpeta}`);
    }
    if (archivo !== insight.data.surfista) {
      errors.push(`insights/${insight.id}.md: el archivo se llama "${archivo}" pero el surfista es "${insight.data.surfista}"`);
    }
    if (!sesiones.has(insight.data.fecha)) {
      errors.push(`insights/${insight.id}.md: no existe la sesión src/content/sesiones/${insight.data.fecha}.es.md`);
    }
  }

  return errors;
}
```

```ts
import { getCollection, type CollectionEntry } from 'astro:content';
import { findContentErrors } from './integrity';

export type Insight = CollectionEntry<'insights'>;
export type Sesion = CollectionEntry<'sesiones'>;
export type Surfista = CollectionEntry<'surfistas'>;
export type Dia = CollectionEntry<'dias'>;

/** Carga todo el contenido del sitio y corta el build si hay referencias rotas. */
export async function loadSite() {
  const [trips, dias, surfistas, sesiones, insights] = await Promise.all([
    getCollection('trip'),
    getCollection('dias'),
    getCollection('surfistas'),
    getCollection('sesiones'),
    getCollection('insights'),
  ]);
  if (trips.length !== 1) throw new Error(`src/data/trip.yaml tiene que tener exactamente un trip (tiene ${trips.length})`);
  const trip = trips[0].data;

  const errors = findContentErrors({
    trip,
    surfistaIds: surfistas.map((s) => s.id),
    dias: dias.map((d) => ({ id: d.id, sesion: d.data.sesion })),
    sesionIds: sesiones.map((s) => s.id),
    insights,
  });
  if (errors.length) throw new Error(`Contenido inválido:\n- ${errors.join('\n- ')}`);

  surfistas.sort((a, b) => a.data.nombre.localeCompare(b.data.nombre, 'es'));

  return { trip, dias, surfistas, sesiones, insights };
}

/** Una página por sesión (en cada idioma, con fallback a español). */
export async function sessionPaths() {
  const { sesiones } = await loadSite();
  const fechas = [...new Set(sesiones.map((s) => s.data.fecha))];
  return fechas.map((fecha) => ({ params: { fecha } }));
}

/** Una página por surfista. */
export async function surferPaths() {
  const { surfistas } = await loadSite();
  return surfistas.map((s) => ({ params: { id: s.id } }));
}
```

```js
  return { nota, focos, logistica };
```

````markdown
### 1. Definir: ida y vuelta con el humano (modelo principal)

1. `brainstorming`: entender qué se quiere, de a una pregunta por vez. Las preguntas visuales se muestran en el companion del navegador. Termina en una spec en `docs/superpowers/specs/AAAA-MM-DD-<tema>-design.md`, aprobada por el humano.
2. `writing-plans`: plan en `docs/superpowers/plans/AAAA-MM-DD-<tema>.md`, con tareas chicas, código completo y comandos con su resultado esperado. **Cada tarea indica qué modelo la ejecuta.** Si hay dudas sobre una API, conviene validarla con una prueba en el scratchpad antes de escribir el plan.

### 2. Ejecutar: subagentes, con el modelo más barato que alcance

`subagent-driven-development`: un subagente nuevo por tarea, con revisión entre tareas.

| Modelo | Para qué |
|---|---|
| **Haiku** | Tareas mecánicas con instrucciones cerradas: cargar un día en `dias.yaml`, agregar un surfista, copiar contenido ya escrito, crear archivos con contenido dado. |
| **Sonnet** | Código con instrucciones claras: componentes, páginas, tests, scripts, traducir al portugués y cargar una sesión nueva desde la transcripción. |
| **Opus (principal)** | Diseño, specs, planes, revisión final, verificación visual y cualquier tarea con decisiones abiertas. |

Si un subagente se traba o la tarea resulta tener decisiones abiertas, vuelve al modelo principal: no se improvisa.

### 3. Cerrar

`verification-before-completion` → `requesting-code-review` → `finishing-a-development-branch`.

## Recetas

### Cargar una sesión nueva con coach  ·  Sonnet

1. Transcribir el audio (fuera del repo) y guardar la transcripción en `sesiones/<fecha>/transcripcion.md`. Es local y no se commitea.
2. Escribir `sesiones/<fecha>/insights-es.md` con el mismo formato que `sesiones/2026-10-26/insights-es.md`: `## Resumen`, un `## <Nombre>` por surfista con `**Lo que salió bien**` y `**En qué trabajar**`, y `## Plan para la próxima sesión` con la tabla (Surfista | Foco principal | Foco secundario | Frase para el agua) y la lista de logística. Citar el minuto de cada insight entre paréntesis.
3. Traducir a `sesiones/<fecha>/insights-pt.md`, con la misma estructura y `## Resumo`.
4. `npm run import-sesion -- <fecha> "<título ES>" "<título PT>"`
5. Agregar o actualizar el día en `src/data/dias.yaml` con `sesion: "<fecha>"`.
6. `npm run check && npm test && npm run build`, y abrir `/sesiones/<fecha>/` en `npm run dev`.
7. Commit `Sesión <dd/mm>: insights` y pedir confirmación para el push.

### Cargar o cambiar un día del calendario  ·  Haiku

En `src/data/dias.yaml`: `id` es la fecha entre comillas, y `actividad` lleva `es` y, si se puede, `pt`. `spot`, `horario` y `sesion` son opcionales. Después, `npm run build`.

### Agregar un surfista  ·  Haiku

1. Agregar `{ id, nombre, color }` en `src/data/surfistas.yaml`. El `id` va en minúsculas y sin espacios, y `color` es uno de `red | sky | yellow | green | pink`.
2. `npm run avatars` genera `public/avatars/<id>.svg`. Para usar una foto, reemplazar ese archivo por un SVG o cambiar `Avatar.astro`.
3. `npm run build`.

### Preparar el repo para otro surftrip  ·  Sonnet

Cambiar `src/data/trip.yaml`, vaciar `dias.yaml`, actualizar `surfistas.yaml` y mover el contenido viejo. Si alguna vez se necesitan varios trips publicados a la vez, el camino previsto es `src/content/trips/<trip-id>/` con rutas `/<trip-id>/...`. Eso es otra spec.
````
